Entry for the [One Word From Your Ex](https://make.fun/bounty/u-brave-eagle-12-one-word-from-your-ex-cfd97ba2) bounty on make.fun.

The program writes exactly one word — the word an ex would use to describe you — to `/output/entry.txt`. Nothing else is written; the word stands alone, with no trailing newline.

## Run

```sh
node main.ts
```

Requires Node 22.18 or later (TypeScript is run as-is). The word is written to `/output/entry.txt` with no trailing newline.
